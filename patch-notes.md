# Version 1.1.16.7

## What's new
- Audio and subtitle choices now use readable full-width cards. Tap Use selected tracks to apply; Cancel keeps the current playback choices.
- Long track labels wrap and scroll on small screens, with action buttons kept visible.
- Audio titles no longer cover the center playback controls. Fullscreen title and Tracks overlays hide and return with the native controls.
- Existing Fit/Crop/Stretch size choices, local subtitles, background audio and update behavior are preserved.

No new app permissions or data collection. Media files stay on the device. This is a playback/UI patch, not a security vulnerability fix. Android emulator checks passed; physical-device, TV/D-pad and TalkBack coverage is not claimed.
